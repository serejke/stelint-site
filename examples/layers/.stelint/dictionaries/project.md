# The terms of the shop

These terms apply to each file of the project.

| Term | Meaning |
|---|---|
| shop | The web store that this project makes. |
| customer | A person who orders products in the shop. |
| product | An article that the shop shows to customers. |
| price | The value of one product. |
| order | A request of a customer for one or more products. |
| order line | One product of an order, with its quantity. |
| to order | A customer sends an order to the shop. |

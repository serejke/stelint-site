# The terms of the project

These terms apply to each file of the project.

| Term | Meaning |
|---|---|
| worker | A thread that makes a copy of one table. |
| CPU core | The part of the CPU that runs one thread at a time. |
| release | One version of the service that we deploy. |
| traffic | The requests that the users send to the service. |
| bastion host | The server that has access to the network of the live service. |

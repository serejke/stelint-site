# Dictionary

This file gives the terms of this website. stelint reads its tables.

| Term | Meaning |
|---|---|
| annotated comment block | A comment block with its prose tree, its sentences, and the UPOS tag and the lexicon entries of each token. |
| attribute | A name and a value of an HTML element. |
| code segment | The part of a prose block that replaces one code span, one URL or one link with only code in its text. |
| code span | Code in backticks in a line of Markdown. |
| comment marker | The characters that start a comment line, for example `///`. |
| CSS | The language that gives the colors and the positions in an HTML page. |
| editor | The part of the first page that shows a text before and after the check. |
| element | One part of an HTML page, for example a paragraph or a link. |
| agent | A program with an LLM that writes code and text, for example Claude Code. |
| beta | A version that its writer uses and examines before the first release. |
| engine | The crate of stelint that loads the configuration and runs the pipeline on each file. |
| MIT license | A software license. A person can use, change and give the code to other persons. |
| GitHub | The service on the network that holds the repository of stelint. |
| JavaScript | The language of the programs in an HTML page. |
| mood | The feature `Mood` of a verb in Universal Dependencies, for example `Imp` for a command. |
| part-of-speech model | A program on the computer that gives the part of speech of each word in a sentence. |
| prose tree | The headings, paragraphs, list items, table cells and code blocks of a comment block. |
| stand-in word | A word that replaces a code token in the text that Stanza reads, for example `Code1`. |
| tag cache | A file that holds the UPOS tags of each sentence that Stanza tagged. |
| UPOS tag | The part of speech of a token in Universal Dependencies, for example `NOUN`. |
| Universal Dependencies | A set of rules that gives the part of speech of each word, in many languages. |
| verb form | The feature `VerbForm` of a verb in Universal Dependencies, for example `Fin`. |
| website | The pages of stelint on the network. |
| word list | A TOML file that gives the approved words. |
| to download | A program gets a file from the network. |

How stelint works

stelint is a compiler for prose. This page follows one comment through the check.

src/lib.rsthe input
/// Retries `req` on transient failures, e.g. if the response isn't [`Ok`].
pub fn send(req: Request) -> Result<Response, SendError> { … }

How stelint finds four errors in one comment.

step 1

Find the prose

stelint reads the comments of a Rust file and the text of a Markdown file. Code in backticks stays code. The rules do not read it.

the prose of the comment
Retries `req` on transient failures, e.g. if the response isn't [`Ok`].
step 2

Find the part of speech

A part-of-speech model on your computer gives each word its part of speech. The same sentence always gets the same result.

step 3

Check the words and the sentences

Each word must be in a word list or in the project dictionary, with that part of speech. The rules also check the length of each sentence.

step 4

Report

Each diagnostic gives the line, the column and a help text. The agent reads the help text.

error[vocabulary]: "transient" is in no word list, dictionary or crate term --> src/lib.rs:1:22 = help: write the text again with different words, or add the word to `.stelint/DICTIONARY.md` error[vocabulary]: "failures" is not an approved noun --> src/lib.rs:1:32 error[latin-abbreviation]: "e.g." is an abbreviation --> src/lib.rs:1:42 = help: write "for example" error[contraction]: "isn't" is a contraction --> src/lib.rs:1:63 = help: write the full words 4 errors, 0 warnings
the agent

Write it again

The agent reads the help texts and the code. It writes the comment again with approved words.

/// Sends `req` again if the response is not [`Ok`].
$ stelint src/lib.rs
0 errors, 0 warnings

The rules go to the agent before it writes.

stelint init writes the writing guides of Claude Code in .claude/rules/. The agent reads them before it writes a comment. It also reads the project dictionary, because stelint-project.md imports it.

A project with many violations can start with a baseline. Then the check fails only on new violations.

.claude/rules/writing guides
stelint-prose.md    # the rules of the prose, each with its rule id
stelint-names.md    # names of the code from the dictionary
stelint-check.md    # when to run stelint, how to correct
stelint-project.md  # your rules: the reader, the sections

How stelint works

One doc comment, from the source file to a comment that passes.

Find the prose

stelint reads Rust comments and Markdown. Code in backticks stays code.

Claude Code reads the writing guides before it writes.

stelint init writes them in .claude/rules/, with a link to the dictionaries.

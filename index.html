    stelint accepts only approved words and short sentences.

    Each entry of a word list gives one word in one part of speech. An agent cannot use an approved noun as a verb. The writing guides give these rules to the agent before it writes.

    1part of speech in each entry of a word list
    1fact or instruction in each sentence
    20words or less in an instruction
    25words or less in a descriptive sentence

    stelint checks the text, and the agent corrects it.

    Deterministic

    stelint

    • The same text always gives the same diagnostics.
    • No LLM and no network in a check.
    • Each diagnostic tells how to correct the text.
    Not deterministic

    The agent

    • It reads the code that the comment is about.
    • It writes the text again until the check passes.
    • It adds a term to the dictionary when the project must have one.

    Try stelint on your project with three commands.

    01

    Install stelint

    The script puts the binary in ~/.local/bin.

    $ gh release download -R serejke/stelint -p install.sh -O - | sh
    02

    Install the part-of-speech model

    The first installation downloads approximately 1 GB. A check does not use the network.

    $ stelint model update
    03

    Start stelint in your project

    It writes .stelint/config.toml and the rules for the agent in .claude/rules/. Then the agent runs stelint and corrects the text.

    $ stelint init

    stelint has built-in word lists for the terms of software and for numbers. A word list is a TOML file. Put the word lists of your project in .stelint/words/.

stelint checks each comment and Markdown file against the terms of your project. A bad sentence fails the check, and the agent writes it again.

    There is too much text.

    An agent writes a hundred lines of comments in one minute. You read the code, not the comments.

    A type checker finds errors in code. stelint finds errors in text. It has no LLM and no network. The same text always gets the same diagnostics, and each diagnostic tells the agent how to correct the text.

    Install.
    
          
    
            
    
              with Claude Code
              
    > /plugin marketplace add serejke/stelint
> /plugin install stelint@stelint
> /stelint:init          # stelint, Stanza, writing guides
> /stelint:word-list     # the STE word list, from its PDF
> /stelint:dictionary    # the dictionaries of your project
> /stelint:correct       # agents correct the errors
    
            
    
            
    
              in a terminal
              
    $ gh release download -R serejke/stelint -p install.sh -O - | sh
$ stelint model update     # Stanza, 1 GB, one time
$ stelint init
$ stelint
    
            
    
          
    
          
    stelint does not include the STE word list. Without it, stelint does not check the words.
